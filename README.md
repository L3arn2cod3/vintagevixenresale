# Vintage Vixen

Booth page for vintagevixenretail.com. Email is jen@vintagevixenretail.com.

Create that mailbox in Microsoft 365 before publishing the form. Shared mailbox is enough if she only needs mail. A user mailbox is better if she will sign in to Outlook herself.

Do not change nameservers. Website DNS gets added beside the existing MX and TXT records.

Azure Static Web Apps Free can host this at $0 with the custom domain and SSL. GoDaddy's free builder cannot use this domain.

Booth name, town, and hours are still a placeholder in the page.
